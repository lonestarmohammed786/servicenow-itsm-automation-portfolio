## Best Projects to Review First

### 1. Incident Caller Validation with GlideAjax

Shows real-time client/server validation using Client Scripts, GlideAjax, and Script Includes.
This project demonstrates practical ServiceNow scripting beyond basic Business Rules.

### 2. Incident Integration Automation

Shows inbound and outbound REST integration patterns using Scripted REST APIs and RESTMessageV2.
This project demonstrates integration readiness and API understanding.

### 3. Import Set & Transform Map Automation

Shows data import, transformation, coalesce logic, reference lookup, skipped-row handling, and import validation.
This project is strong for ServiceNow admin and data quality work.

### 4. CMDB Data Quality & CI Relationship Automation

Shows CMDB validation, duplicate CI prevention, CI ownership checks, support group validation, and Incident-to-CI visibility.
This project demonstrates CMDB and ITSM process understanding.

### 5. Asset Lifecycle Automation

Shows hardware asset lifecycle validation, assigned user checks, asset-to-CI alignment, lifecycle work notes, and asset reporting.
This project connects well with IT Asset Management and Enterprise IT Support.

### 6. ServiceNow Security & Access Control Automation

Shows user, group, and role governance using `sys_user`, `sys_user_grmember`, and `sys_user_has_role`.
This project demonstrates platform governance and access review exposure.

### 7. Scheduled Jobs & Notifications Automation

Shows scheduled checks, reminder-style automation, and recurring ITSM review using GlideRecord and GlideAggregate.
This project demonstrates automation that runs without user form action.
