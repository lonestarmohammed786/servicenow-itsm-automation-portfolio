# Incident Caller Validation with GlideAjax

This project contains ServiceNow GlideAjax validation examples for the Incident form using Client Scripts and client-callable Script Includes.

## Focus Areas

- GlideAjax
- Script Includes
- AbstractAjaxProcessor
- Client-callable server-side validation
- GlideRecord
- Reference field sys_id handling
- onChange Client Scripts
- Real-time Incident form validation

## Scripts Included

- Caller Inactive Check
- Caller Manager Check
- Caller Department Check
- Caller Active Incident Check
- Assignment Group Inactive Check

## Purpose

The goal of this project is to demonstrate production-style ServiceNow GlideAjax patterns by validating Incident form data in real time before record submission.
