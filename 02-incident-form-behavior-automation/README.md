# Incident Form Behavior Automation

This project contains ServiceNow Client Script examples that improve Incident form behavior and guide users before submission.

## Focus Areas

- onChange Client Scripts
- onSubmit Client Scripts
- g_form.setValue()
- g_form.setMandatory()
- g_form.getValue()
- g_form.addInfoMessage()
- g_form.addErrorMessage()
- Field clearing logic
- Form validation

## Scripts Included

- Priority Critical → Assignment Group Mandatory
- Category Network → Impact and Urgency High
- Category Hardware → Subcategory Mandatory
- Short Description Contains Urgent → Priority Critical
- Assignment Group Cleared → Assigned To Cleared
- onSubmit Critical Incident Assignment Group Validation

## Purpose

The goal of this project is to demonstrate production-style ServiceNow form behavior automation using Client Scripts on the Incident table.
