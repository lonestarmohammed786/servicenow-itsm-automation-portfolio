# Incident Integration Automation

This project contains ServiceNow inbound and outbound REST integration examples for Incident Management.

## Focus Areas

- Scripted REST APIs
- RESTMessageV2
- GlideRecord
- JSON payload handling
- request.body.data
- response.setStatus()
- response.setBody()
- getStatusCode()
- getBody()
- Integration logging
- Error handling

## Scripts Included

- Inbound REST API: Create Incident
- Inbound REST API: Add Work Note by External Ticket ID
- Outbound REST: Critical Incident Alert
- Outbound REST: Resolved Incident Notification
- Integration Logging using Work Notes
- Catch Block Error Handling

## Purpose

The goal of this project is to demonstrate production-style ServiceNow integration patterns where ServiceNow receives data from external systems and sends outbound notifications to external APIs.
